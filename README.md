# Étude — GitHub + AI

Upload every file and folder in this download to your GitHub repository.
Keep index.html at the top level. Turn on Pages using main and /(root).

The AI generator is included. Follow [AI_SETUP.md](AI_SETUP.md) to connect the
included Cloudflare Worker and add your OpenAI API key as a server secret.
GitHub Pages alone does not activate the AI service.

Study room, To-do list, PDF imports, flashcards, quizzes, recordings and local
saves are included. Open your website link from Settings → Pages to use the app.
